🛠️ 零挫折保證：常見排錯 4 大檢核圖解

        
99% 的發布卡關都在以下四個微小細節中解決

      


      

        

          
          

            
⏳

            

              
1. 打開網頁顯示 404？

              
➔ 等候 1~2 分鐘建立快取

              
或確認儲存庫是否設為 Public（公開）

            

          


          
          

            
📄

            

              
2. 打開一片空白？

              
➔ 檔名必須是 index.html (全小寫)

              
若寫成 Index.html 或 game.html 伺服器無法辨識

            

          


          
          

            
🛑

            

              
3. 點擊按鈕沒有反應？

              
➔ 請 AI 重新檢查 JS 綁定

              
對話框輸入：「按鈕未觸發，請重新給單一 index.html」

            

          


          
          

            
🔄

            

              
4. 修改題目後如何更新？

              
➔ 在 GitHub 編輯 index.html 點 Commit

              
網址不用變，30 秒自動更新上線！
