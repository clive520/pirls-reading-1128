          步驟 01 / STEP 01
          Google AI Studio
          Publish to GitHub
        

        
🚀 一鍵上雲：從 AI Studio 推送到 GitHub（Publish / Push）

        
善用 AI Studio 工具列的 GitHub 整合按鈕，免開終端機、免裝 Git，一鍵建立雲端儲存庫！

      


      

        

          

            

              
1

              

                
點擊右上角 GitHub 貓咪圖示 / Publish

                
在 AI Studio 畫面右上角，找到 GitHub 圖示或 Publish 按鈕並點擊展開發布選單。

              

            


            

              
2

              

                
授權 GitHub 帳號連線

                
首次使用時點擊「Authorize Google」，授權 AI Studio 幫您在 GitHub 建立專案。

              

            


            

              
3

              

                
輸入儲存庫名稱（Repository Name）

                
建議使用英文字母與連字符（例如 idiom-game 或 math-challenge），不可包含空格。

              

            


            

              
4

              

                
確認設為 Public 並點擊 Push

                
將可見性設為 Public（公開），按下 Push 按鈕，AI 自動建立 Repo 並上傳程式碼！

              

            

          

        


        

          

            

              
💡 極速雙保險：手動複製貼上法（30秒備用路線）

              

                如果 AI Studio 暫時無法授權 GitHub，老師可以直接用最直覺的「手動建檔」備案：
              

              

                

                  ①
                  在 AI Studio 按 Copy Code 複製全部 HTML。
                

                

                  ②
                  前往 GitHub 首頁 ➔ 點擊右上角綠色 New 建立新儲存庫。
                

                

                  ③
                  點擊 Add file ➔ Create new file，檔名精確輸入 index.html。
                

                

                  ④
                  貼上代碼，拉到最下方點擊綠色 Commit changes 即可！
                

              

            

            

              ✨ 核心關鍵：只要根目錄有名為 index.html 的檔案，GitHub 就具備即時發布的能力！

🌐 點亮全世界：GitHub Pages 公開設定 3 步驟

        
在 GitHub 儲存庫中只要點選 3 次滑鼠，零主機設定，免費全球高可用 CDN 立即生效！

      


      

        

          

            

              
1

              

                
點擊儲存庫上方「Settings」齒輪

                
進入您剛才建立的遊戲儲存庫頁面，在最上方導航列右端點擊齒輪 Settings。

              

            


            

              
2

              

                
在左側選單點選「Pages」標籤

                
在左側導航選單中找到「Code and automation」分組下的 Pages 點擊進入。

              

            


            

              
3

              

                
選擇 main 分支與 /(root) 並點擊 Save

                

                  • Build and deployment 保持預設「Deploy from a branch」

                  • Branch 下拉選單選擇 main

                  • 資料夾保持 / (root) ➔ 按下右側綠色 Save！

🛠️ 零挫折保證：常見問題排錯檢核表

        
遇到狀況別慌張！99% 的卡關問題都在以下四個微小細節中解決。

      


      

        

          

            

              
1

              

                
狀況：打開網址出現 404 There isn't a GitHub Pages site here?

                
原因與解法：首次設定 Pages 後，GitHub 雲端需要 1~2 分鐘建立快取。喝口水稍候重新整理即可；同時檢查該 Repo 是否誤設為「Private」（免費用戶需設為 Public 才能啟用 Pages）。

              

            


            

              
2

              

                
狀況：打開網頁一片空白，或是只看到資料夾檔案列表？

                
原因與解法：根目錄檔案名稱必須百分之百精確為全部小寫的 index.html！若拼成 Index.html、game.html 或 index.htm，伺服器將無法自動辨識首頁。

              

            


            

              
3

              

                
狀況：遊戲畫面很漂亮，但點擊開始或按鈕時完全沒有反應？

                
原因與解法：AI 生成代碼時可能 JS 未正確掛載。只需將畫面複製回 AI Studio 對話框輸入：「按鈕點擊未觸發事件，請檢查並重新輸出單一完整的 index.html 檔案」，AI 即可自動修復。

              

            


            

              
4

              

                
狀況：我修改了提示詞產生新版遊戲，該如何更新上線網址？

                
原因與解法：完全不需要重新設定 Pages！只需在 GitHub 儲存庫中點擊 index.html ➔ 點右上角鉛筆圖示編輯 ➔ 貼上新代碼並點擊 Commit，GitHub 會在 30 秒內自動秒級同步更新。
