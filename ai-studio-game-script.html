⏱️ 建議時間：1.5 分鐘

🎬

💬 講者口語逐字稿

各位現場的老師、夥伴們，大家早安！非常高興今天能在這裡跟大家分享一個超級令人振奮的主題：「10 分鐘打造全班可玩的課堂小遊戲」！

很多老師平時在班上帶閱讀、教國語成語、或者是做數學心算練習的時候，都很想做成趣味互動小遊戲給孩子們玩。但過去我們總覺得：「天啊，這是不是要資優班電腦老師、或者是資訊組長寫幾百行程式碼才能做出來？」

今天我要跟所有非資訊專長的老師保證：完全不需要寫一行程式碼！ 我們只要掌握今天這套「零伺服器、零付費金鑰、零終端機指令」的現代 AI 工作流——從我幫大家整理好的「提示詞庫」出發，貼進 Google 免費的 Google AI Studio，再透過 GitHub Pages 一鍵發布，短短 10 分鐘，你專屬的教學小遊戲就上線了！全班小朋友只要拿著平板掃描 QR Code，立刻就能進行課堂熱身或課後複習。

現在就請大家跟著我的節奏，我們一步一步把這項課堂黑科技帶回學校！

SLIDE 02

認識神器：Google AI Studio 介面與核心設定 (Gemini 3.8 Flash)

⏱️ 建議時間：2.0 分鐘
🎯 本頁核心目標： 介紹 Google AI Studio 網頁介面。強調目前主力為 Gemini 3.8 Flash（速度極快、推理強大、免費額度充足），並說明最關鍵的核心架構「純前端單一 index.html 模式」，讓老師明白為何這個模式 100% 能在 GitHub Pages 上線。
🎬
【講者動作指示】 用雷射筆指著大螢幕上的介面三方架構圖：左側 Prompt 提示詞框、中間 Run 執行箭頭、右側 Live Preview 即時渲染區，以及下方的單一 index.html 打包公式。特別在提到「Gemini 3.8 Flash」時加重語氣。
💬 講者口語逐字稿

首先，我們要認識我們今天的超級大腦：Google AI Studio。大家可以直接在瀏覽器輸入 aistudio.google.com，用你的 Google 帳號就能免費登入。

請大家看投影片右側的介面圖解。最上方有一個非常關鍵的下拉選單：Model 模型選擇，請大家認準目前最新旗艦的「Gemini 3.8 Flash」！ 為什麼選它呢？因為 3.8 Flash 的生成速度快到不可思議，而且它的代碼推理能力特別敏銳，在生成 HTML、CSS 和 JavaScript 綜合網頁時，結構乾淨又穩定，更棒的是 Google 提供給教育者非常充裕的免費額度，完全不需要綁定信用卡！

那今天最精華的「通關秘笈」是什麼？請看左邊第 4 點：「純前端單一 index.html 模式」。 以往做網頁可能需要安裝 Node.js、Vite 打包，還要把檔案切成好幾個資料夾，對老師來說太複雜了。我們今天所有的提示詞，都嚴格要求 Gemini 把「遊戲畫面（HTML）」、「美化樣式（CSS）」和「遊戲邏輯與計分音效（JavaScript）」全部打包在單單一個 index.html 檔案裡！

單一檔案意味著什麼？意味著零門檻、零出錯率！丟到哪裡都能秒開，這就是我們能 10 分鐘快速發布的秘密！

🎬
【講者動作指示】 現場點選左側 8 大遊戲按鈕，展示成語連線、單字翻牌、心算愛心血條等生動的圖形化示意，再示範點擊右側綠色的「一鍵複製提示詞」按鈕，讓大螢幕跳出「✅ 已複製！」提示，加深老師印象。
💬 講者口語逐字稿

好，工欲善其事，必先利其器！老師們最常遇到的問題不是不會用 AI，而是「不知道該怎麼跟 AI 開口」，對不對？

大家看畫面右上角有一個綠色按鈕：「📋 複製本提示詞」。只要輕輕點一下，整篇完整嚴謹的提示詞就會複製到你的剪貼簿。 請老師特別注意提示詞中我用中括號標註的【題庫區】，例如成語清單或英文單字。老師只要把裡面的詞彙換成你明天要教的第 5 課生字或段考單元，按下 AI Studio 的 Run，你的專屬小遊戲就立刻誕生了！

SLIDE 04

🚀 一鍵上雲：從 AI Studio 推送到 GitHub（Publish / Push）

⏱️ 建議時間：2.5 分鐘
🎯 本頁核心目標： 圖解將 AI Studio 成果上傳到 GitHub 的操作流程。重點標示右上角 GitHub 貓咪圖示、授權設定、儲存庫命名（英文無空格）與設為 Public，並提供 30 秒手動複製貼上建檔的雙保險備案。
🎬
【講者動作指示】 指著投影片上的 4 步管道圖（1.貓咪圖示 ➔ 2.授權連線 ➔ 3.命名Repo ➔ 4.Push推送）與下方的雙保險備用卡片。特別提醒「命名限英文無空格」與「設為 Public」這兩個關鍵點。
💬 講者口語逐字稿

好！遊戲在 AI Studio 生成並測試滿意之後，接下來就是最關鍵的一步：怎麼讓全世界、全班的孩子都能連上線？

請大家看投影片第 4 頁。在 Google AI Studio 的右上角工具列，大家會看到一隻黑色的貓咪圖示，或者寫著「Publish / Export to GitHub」。 我們點下去之後，流程只有簡單四步： 第一步，點擊授權「Authorize Google」，讓 Google 連接到你的 GitHub 帳號； 第二步，給你的遊戲取個名字，請特別注意：只能用英文字母、數字或連字符（-），例如 idiom-game 或 math-101，千萬不要打中文或空格喔！ 第三步，確認可見度勾選為 Public（公開）； 最後，按下綠色的 Push 按鈕！

AI Studio 就會像光速快遞一樣，把剛剛寫好的遊戲自動打包並推送到你的 GitHub 上面，連終端機都不用開！

那萬一現場網路卡住、或者你不想授權帳號呢？請看下方為大家準備的「極速雙保險」：在 AI Studio 點「Copy Code」複製全部代碼，到 GitHub 點 New 建立新儲存庫，新增檔案名稱精確寫上 index.html，貼上並存檔，效果完全一模一樣！

SLIDE 05

🌐 點亮全世界：GitHub Pages 公開設定 3 步驟

⏱️ 建議時間：2.0 分鐘
🎯 本頁核心目標： 教學員在 GitHub Repository 內設定 Pages 的標準 3 次點擊動作（Settings ➔ Pages ➔ main / root ➔ Save），並解讀建置成功後出現的綠色公開網址。
🎬
【講者動作指示】 指著投影片上的 3 個大按鈕圖解（⚙️ Settings ➔ 📄 Pages ➔ 🌿 main + Save）與下方的綠色成功狀態條。帶著全場老師一起念「齒輪 ➔ Pages ➔ main ➔ Save」這四字口訣。
💬 講者口語逐字稿

檔案已經上傳到 GitHub 了，最後一步，也是最神奇的魔法：如何把它變成一個真正的公開網站？

只要三個點擊動作，大家可以跟著我口訣念一次：「齒輪 ➔ Pages ➔ main ➔ Save！」

第一下：在儲存庫右上角點選齒輪圖示的 Settings； 第二下：在左邊選單往下拉，找到 Pages 點進去； 第三下：在中間的 Branch 下拉選單中，選中你的主分支 main，後面資料夾保持預設的 / (root)，然後按下右邊綠色的 Save！

按下去之後，GitHub 的全球伺服器就開始在背後為你架站了。通常只要等 30 秒到 1 分鐘，重新整理頁面，頂部就會出現一塊漂亮的綠色卡片：「Your site is live at...」，後面跟著一串藍色的專屬網址！ 恭喜大家，從這一秒開始，你的小遊戲正式發布到全世界的網際網路上了！

SLIDE 06

📲 課堂發布：專屬網址與 QR Code 實戰應用

⏱️ 建議時間：2.5 分鐘
🎯 本頁核心目標： 解析 GitHub Pages 的固定網址結構，示範如何用 Chrome 瀏覽器右鍵產生大螢幕投影 QR Code，並盤點「零登入、跨載具、永久免費」的三大教學優勢。
🎬
【講者動作指示】 指著投影片上的大螢幕 QR Code 投影情境圖，說明平板與 Chromebook 掃碼即玩。可以用手機或現場平板實際示範掃描投影幕上的 QR Code，展現「3 秒進入遊戲」的無縫體驗。最後充滿熱情地做出結語，邀請老師打開電腦現場練習。
💬 講者口語逐字稿

拿到網址之後，很多老師會問：「這串英文看起來很長，小朋友在平板上很難輸入，怎麼辦？」

大家看畫面左側，教大家一個 Chrome 瀏覽器的隱藏神技： 在你的遊戲網頁上，任意空白處按一下滑鼠右鍵，選單裡就有一個「以此頁面建立 QR 圖碼」！ 它會直接在螢幕上跳出一個清晰的 QR Code，你直接把它投影到教室的大黑板或電子白板上。

學生早自習進教室、或者是課堂最後 10 分鐘，拿起學校配發的生生用平板（iPad）、Chromebook、甚至是借用手機，相機一掃，不用 3 秒鐘，全班就直接進入成語配對大挑戰！

請大家看畫面右側我特別整理的這三大優勢： 第一、學生完全不用註冊或登入任何帳號，免除忘記密碼或家長個資疑慮； 第二、全平台相容，不管是 iOS、安卓還是電腦螢幕通通完美適應； 第三、終身免伺服器費用！微軟 GitHub 全球邊緣節點免費託管，即使全校 30 個班級同時上線玩，也不用擔心伺服器當機或被收費！

老師們，未來的教學是人機協同的時代。當我們懂得運用 AI 的創造力加上 GitHub 的傳播力，每一位老師都能成為孩子心目中最酷的數位互動魔術師！ 謝謝大家，現在就請大家打開瀏覽器，我們一起動手做出第一款專屬小遊戲吧！
