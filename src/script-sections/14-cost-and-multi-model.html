理想很豐滿、現實很骨感：AI 成本考量與多模型彈性架構

⏱️ 建議時間：3 ~ 4 分鐘
投影片畫面： 「系統與 API 設定」介面截圖（Google Gemini、OpenRouter、DeepSeek 官方 API 切換選擇、自備金鑰加密輸入、模型下拉選單、API 偵測按鈕）。
🎭 現場身態與互動： 語調幽默、會心一笑，接著轉為務實共鳴！雙手一攤笑著說：「老師們，大家都說 AI 好棒，但只要走出研習會場，校長跟資訊組長一定會問：『這到底要花多少錢？』今天我就把現實底牌翻開給大家看！」

各位老師，常言道：「理想很豐滿，現實很骨感！」

我們前面看了這麼多令人興奮的 AI 功能——自動出題、秒級批改、雷達圖、補救教案……但只要動用到 AI，第一線學校馬上就會面臨最真實的兩大挑戰：
第一：花費考量！全校幾百個學生每天做閱讀測驗，API 費用會不會把學校經費吃垮？
第二：穩定度考量！免費的 AI 工具雖然好，但常常遇到「額度不足 (Rate Limit)」，或是全班同時繳卷時「反應過慢、尖峰塞車」直接轉圈圈斷線！

大家請看大螢幕這張【系統與 API 設定介面】！我們在系統設計之初，就為學校解決了這個致命痛點，打造了三軌並行的多元模型生態：

【解方一 • 性價比之王】：支援 DeepSeek 官方 API！
這是我個人極力推薦的解決方案！DeepSeek 的官方 API 價格低到不可思議，批改全班 30 份問答題花費不到幾毛錢台幣！而且它是專有 API 通道，反應速度極快、幾乎零延遲，徹底解決學校長期常態化運行的經費焦慮！

【解方二 • 多元模型生態】：整合 OpenRouter 聚合平台！
如果您想使用全世界最頂級的 Claude 3.5 Sonnet 或 OpenAI GPT-4o，您只要輸入 OpenRouter 金鑰，就能一鍵自由切換！學校完全不需要被任何單一商業廠商技術綁定，隨時掌握全球最先進的模型！

【解方三 • 預設即開即用】：內建 Google Gemini 額度！
對於剛入門、不想繁瑣設定的老師，系統預設直接調用 Google Gemini，零門檻即開即用！更重要的是，所有老師自備的 API Key 都安全加密儲存在自己的帳號中，確保學校資料隱私與自主權。

💰 老師們，一套能真正走進教室、長久運作的教育系統，不能只有高大上的口號，更要有平易近人的成本架構！用最便宜的花費、最穩定的速度，讓全班每一位孩子天天都能享受頂級 AI 家教的陪伴！
